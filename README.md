 # Security Research

Public notes from my smart contract security practice.

I'm Tammy ([@TammyBuilds](https://x.com/TammyBuilds), [github.com/justtammy2](https://github.com/justtammy2)), learning smart contract security in public. This repo is where I write up what I learn from Ethernaut challenges and audit reports I study on Solodit.

For CodeHawks First Flight contest writeups, see: [link to second repo]

Currently on a 100-day challenge to land my first valid finding in a smart contract audit contest.

The goal is to build pattern recognition through public work. Everything here is written for my future self first — clear enough that I could re-read it in six months and rebuild the reasoning.

## Structure

- `ethernaut/` — Solutions and lessons from Ethernaut CTF levels
- `solodit-notes/` — Pattern notes from audit reports

## Format

Each writeup covers: the vulnerability, why it works at the code level, the exploit, and the mitigation. Notes also include what tripped me up — the personal debugging log matters more than the solution.
